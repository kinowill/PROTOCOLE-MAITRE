conservé tel quel. Le présent adaptateur résume l'essentiel.

## Surfaces d'injection

- Global : `~/.codex/AGENTS.md`
- Projet : `AGENTS.md` à la racine
- Limites de taille : `project_doc_max_bytes` dans `~/.codex/config.toml`

## Installation du protocole

Coller l'intégralité de `NOYAU.md` dans l'`AGENTS.md` global ; ajouter les
spécificités du projet dans l'`AGENTS.md` projet. Parcours détaillés :
PROTOCOLE-CODEX `integrations/codex.md`.
