# Adaptateur — Outils génériques

Pour un autre outil, consulter sa documentation officielle et sa version installée afin d'identifier les instructions persistantes globales, celles du projet, les permissions et les moyens de vérification. Les anciennes conventions et interfaces varient selon les versions.

Préserver les instructions et la configuration existantes ; installer le noyau intégral une seule fois dans une surface réellement chargée. Garder la référence disponible à la demande et les spécificités dans le projet. Ne pas modifier les fournisseurs ou leurs identifiants pour installer le protocole.

Exécuter le contrôle statique, puis SM-01 dans une nouvelle session : un fichier présent ne prouve ni son chargement ni le respect des règles. Tester aussi la reprise après compaction et chaque modèle utilisé. Les capacités et la fiabilité varient selon les outils et modèles ; documenter les observations sans généralisation non mesurée.
